## The theme of the day: access is a platform problem, not a ticket queue

More than half of today's "fires" were the same shape underneath — someone had the wrong level of access to the wrong thing. Different systems, different owners, same root cause. When you see a pattern repeat that hard, it stops being a support issue and starts being an architecture issue.

### Fire #2 — An ARM deployment failing on "missing parameter definition"

## The one that's still fighting me: the legal-AI agent

## Standing takeaways

- **If a routine deploy can silently break security, security wasn't really deployed.** Put it in code.
- **The fastest debugging tool is often just searching the literal error text** and diffing "what I declared" against "what I provided." Unglamorous, reliably effective.
- **"Works standalone, fails in orchestration" = look at the boundary,** not the component.
- Firefighting feels productive but it's interest payment on a design debt. The real work is turning each fire into a pattern so it never burns twice.
